# KITCHEN STOCK
飲食店向け在庫・発注管理のブラウザ保存型MVP。

## 起動
このフォルダで `npm install`、`npm run dev` を実行し http://127.0.0.1:4173 を開く。
開発サーバーには Python 3 を使用します。
依存パッケージ・ビルド工程は不要。`node --check dist/app.js` で構文確認。

## 機能
- 食材登録・編集、仕入先・単価・発注点設定
- 検索、カテゴリ・要発注フィルタ
- 入庫、出庫、廃棄、棚卸と履歴
- 発注点以下の食材から仕入先別に発注作成（未入荷数量を控除）
- 一括入荷と在庫加算、二重入荷防止
- 在庫CSV、発注CSV、JSONバックアップ出力

## 初期版の範囲
架空の食材データ10品目から開始。データは同一ブラウザ・同一オリジンのlocalStorageに保存。
複数端末・スタッフ間の同期、発注先への送信、分納・発注取消、期限・ロット管理、バックアップ復元は未実装。
ブラウザのサイトデータ削除で記録が消えるため、必要な記録はバックアップを保存する。
発注の「発注済み」はアプリ内の管理状態であり、仕入先への送信完了を意味しない。
本運用向けには共有DB・認証権限・復元・並行更新対応を追加する。

## 動作確認
ブラウザで不足5食材→仕入先4社への発注分割、トマト8kg入荷（2→10kg）、再読込後の永続化を確認。
